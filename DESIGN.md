# Fit — visual system

This product follows the owner canon in [`00_DESIGN_BY_PRODUCT_NOT_TEMPLATE.md`](./00_DESIGN_BY_PRODUCT_NOT_TEMPLATE.md):

> Design the visual for the audience, the tool’s real-world association, the atmosphere, the niche, and the theme. Do not clone the previous Free App. Do not run “block 7” (if paper/copper → force Swiss) as a substitute for design.

## Why Fit looks like a dark studio

| Question | Answer |
|----------|--------|
| Audience | Someone who needs **exact pixels** for Instagram, YouTube, X, TikTok — often on a phone |
| Association | Cropping, Lightroom, Photoshop, ground glass, a studio monitor |
| Atmosphere | The photo glows; the chrome stays quiet |
| Niche | Privacy-first resizer (Canvas resample, honest upscale badge) |
| Theme | **Fit** = put the picture in a frame. CTA = Resize |
| Not | Nota’s invoice paper, Folio’s desk, Crush/Shift/Strip cream+copper clone |

Tokens live in `src/styles.css` `@theme`. Do not reintroduce Fraunces, Figtree, `#f3eee4`, `#b45309`, or `rounded-full` as the system radius.

Header mark: crop-frame SVG, not a letter in a copper disc.
