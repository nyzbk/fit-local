# Fit — Free Image Resizer

Resize photos for Instagram, YouTube and X in the browser. Exact pixels, social presets, Fill / Fit / Stretch, batch ZIP.

No upload. No signup. No watermark.

- Domain: [fit-local-six.vercel.app](https://fit-local-six.vercel.app)
- Repo: [nyzbk/fit-local](https://github.com/nyzbk/fit-local)
- Design canon: [`00_DESIGN_BY_PRODUCT_NOT_TEMPLATE.md`](./00_DESIGN_BY_PRODUCT_NOT_TEMPLATE.md)

Processing is 100% client-side (`createImageBitmap` + Canvas + `toBlob` + JSZip). Canvas resample — not lossless JPEG, not AI upscale.
